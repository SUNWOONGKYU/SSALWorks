# SSAL Works에 오신 것을 환영합니다

**SSAL Works**는 Claude Code를 활용하고 차별화된 체계적 방법론을 적용하여 풀스택 웹사이트를 개발하는 플랫폼입니다.

### SSAL Works의 10가지 차별점

| # | 구분 | 차별점 | 설명 |
|---|------|--------|------|
| 1 | 방법론 | **10단계 프로세스** | P0~P3 기획 + S0~S5 개발, 전체 개발 여정 |
| 2 | 방법론 | **SAL Grid** | 개발 단계(S0~S5)를 5 Stage × 11 Area로 좌표화 |
| 3 | 방법론 | **3단계 검증 시스템** | 작업자 → 검증자 → 최종승인 분리 |
| 4 | 방법론 | **7대 Rules + 3대 Methods + 12대 Compliance** | AI 행동 규칙 체계 |
| 5 | 도구 | **Dev Package** | 프로젝트 등록 시 자동 생성, 완벽한 폴더 구조 |
| 6 | 도구 | **Order Sheet** | 단계별 AI 작업 지시 문서 50개 이상 |
| 7 | 도구 | **SAL Grid Viewer** | 개발 단계 진행 현황 실시간 시각화 |
| 8 | 콘텐츠 | **학습 콘텐츠** | Books 87편 + Tips 67개 + Guide 5개 |
| 9 | 콘텐츠 | **AI Tutor** | 질의응답으로 학습 지원 |
| 10 | 서비스 | **1:1 코칭 3개월** | 개발 + 창업 + 경영 자문 |
