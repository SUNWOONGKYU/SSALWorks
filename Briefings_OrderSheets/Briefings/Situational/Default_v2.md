# SSAL Works에 오신 것을 환영합니다

<span style="color: #6B7280;">※ 모바일에서는 조회만 가능합니다. 개발 작업은 PC에서 진행하세요.</span>

**SSAL Works**는 **Claude Code**(Anthropic의 AI 코딩 도구)를 활용하고, **SAL Grid**(Stage×Area×Level 3차원 좌표계)로 모든 작업을 체계적으로 관리하여 **풀스택 웹사이트**(프론트엔드+백엔드가 완비된 실제 비즈니스용 웹사이트)를 개발하는 플랫폼입니다.

**SSAL** = S(Sunny) + SAL(Stage, Area, Level). 한글 발음 "쌀"은 핵심 먹을거리. 황금쌀 방앗간처럼, 아이디어를 가져와 돈 버는 웹사이트를 만드는 곳입니다.

코딩을 몰라도, 아이디어와 의지만 있으면 AI와 함께 완전한 웹사이트를 만들 수 있습니다.

---

## 10가지 차별점

**[방법론 4가지]**

1. **10단계 프로세스** - P0~P3(기획 4단계) + S0~S5(개발 6단계)로 아이디어부터 배포까지 체계화
2. **SAL Grid** - 5 Stage × 11 Area × 3 Level 좌표계로 66개 Task를 22개 속성으로 관리
3. **3단계 검증** - 작업 AI → 검증 AI → PO 최종승인. 작성자와 검증자 분리로 품질 확보
4. **AI 규칙 체계** - 7대 Rules + 3대 Methods + 12대 Compliance로 AI가 실수하지 않도록 통제

**[도구 3가지]**

5. **Dev Package** - 프로젝트 등록 시 자동 다운로드. 폴더 구조, 규칙 파일, 설정 일체 포함
6. **Order Sheet** - 단계별 AI 작업 지시서 30개. 복사해서 Claude Code에 붙여넣기만 하면 작업 시작
7. **SAL Grid Viewer** - 66개 Task 진행 현황을 실시간 시각화. 완료율, 검증 상태, 다음 할 일 확인

**[콘텐츠 2가지]**

8. **학습 콘텐츠** - Books 82편 + Tips 65개 + 외부 연동 Guide 5개. 초보자도 따라할 수 있는 수준
9. **AI Tutor** - 모르는 것은 AI에게 질문. 학습 콘텐츠 기반으로 맞춤 답변 제공

**[서비스 1가지]**

10. **1:1 코칭 3개월** - Sunny가 개발 막힌 곳 해결 + 창업/사업 방향 자문

## 바이브 코딩이 아닙니다

바이브 코딩 = 체계 없이 AI에게 "이거 해줘"라고만 시키는 방식. 파일이 난립하고, 코드가 엉키고, 수정이 불가능해집니다.

SSAL Works는 정반대입니다. 10단계 프로세스로 전체를 관리하고, SAL Grid로 모든 Task를 추적하고, Order Sheet로 체계적으로 지시합니다. AI가 지켜야 할 Rules, Compliance, Methods까지 정의되어 있습니다.

---

## 작업 방식: 인간과 AI의 역할 분담

**AI(Claude Code)가 담당**: 코딩, 문법, 도구 사용, 반복 작업, 기술적 구현

**인간(빌더)이 담당**: 무엇을 만들지 결정, 방향 설정, 비즈니스 모델, 단계별 승인, 최종 배포

**"무엇을 만들 것인가"는 인간이 결정하고, "어떻게 만들 것인가"는 AI가 담당합니다.**

## 빌더 계정

**빌더(Builder)**란 단순히 웹사이트를 만드는 사람이 아니라, 웹사이트를 통해 비즈니스를 실현하는 사람입니다. 빌더는 기획하고, 의사결정하고, 방향을 정합니다. AI는 빌더의 지시에 따라 코딩을 수행합니다.

빌더 계정을 개설하면 실제 개발 작업을 시작할 수 있습니다.

**빌더 계정으로 할 수 있는 것**

- 10단계 프로세스로 체계적 개발, Project SAL Grid로 66개 Task 관리
- Dev Package 다운로드, Order Sheet 30개로 AI 작업 지시
- Books 82편, Tips 65개, 외부 연동 Guide 5개, AI Tutor 질의응답
- SSAL Works 예시 프로젝트 전체 소스코드 참조

**가격**

- **빌더 계정 개설비**: 300만원 (얼리버드, 부가세 포함) → 향후 3,000만원까지 단계적 인상 예정
- **50% 환불 인센티브**: 3개월 내 웹사이트 완성 + 고객 30명 확보 시 150만원 환불
- **플랫폼 이용료**: 처음 3개월 면제, 이후 월 5만원

<span style="color: #D97706;">**개설 방법**: 왼쪽 사이드바 → My Page → 서비스 이용 현황 → 빌더 계정 개설비 납부</span>

**빌더 계정 개설 후 진행 순서**

1. **프로젝트 등록** - 개설 완료 후 프로젝트 정보 입력
2. **Dev Package 다운로드** - 등록 완료 시 자동 다운로드 (압축 풀고 원하는 폴더에 저장)
3. **Claude Code 실행** - 작업 폴더에서 마우스 오른쪽 → "터미널에서 열기" → `claude` 입력
4. **개발 환경 설정** - Claude Code에게 "개발 환경 확인해줘"라고 말하면 필요한 도구 설치 안내
5. **10단계 프로세스 진행** - 각 단계마다: 안내문 확인 → Order Sheet 작성 → Claude Code에 전달

<span style="color: #059669;">**첫 시작**: 프로젝트 등록 → Dev Package 다운로드 → Claude Code 실행 → 개발 환경 설정</span>
