우선, SSAL Works에서 무엇을 어떻게 해야 하는지에 대해서 간략히 안내해 드리겠습니다.

무료로 일단 회원 가입을 하시고 플랫폼을 전체적으로 찬찬히 둘러보세요. 메인 화면 왼쪽편에서는 프로젝트 진행 프로세스 관리방법, 단계별로 제시되어 있는 34개의 안내문과 32개의 Order Sheet 템플릿을 살펴보고, 중앙의 윗쪽에서는 Control Desk 사용방법, Order Sheet 작성방법을 살펴보고, 그리고 중앙의 아랫쪽에서는 3차원 SAL Grid Viewer를 열어서 63개 이상의 Task가 어떻게 체계적으로 관리되고 있는지 놀라운 모습을 한번 확인해보고, 오른쪽편에서는 Claude & Claude Code 사용법부터 풀스택 웹사이트 개발 기초지식과 프로젝트 관리 방법까지 다루는 80편의 Books, 18개 분야에 걸친 65개의 실전 Tips, 외부 연동 설정 Guide 5개까지 방대한 지식을 모두 무료로 열람하실 수 있습니다. 그리고 나서, 하단 Footer에 있는 서비스 소개 내용을 읽어보세요. 필요성이 있고 매력이 느껴지시면, 바로 빌더 계정을 개설하신 후에 본인의 창의적인 아이디어가 구현된 풀스택 웹사이트 개발 작업을 시작하세요.

참고로 모바일 버전에서는 조회는 모두 가능하지만 작업에는 제한이 있으므로 개발 작업은 PC버전에서 하는 게 편리합니다.

빌더 계정을 개설하면 아래와 같은 엄청난 기능 10가지를 사용할 수 있습니다.

- 프로젝트를 등록하고 SSAL Works Dev Package(개발환경 설정용 폴더와 파일 일체)를 다운로드 받아서 설치
- Rules(AI 7대 작업 규칙), Compliance(AI 12대 준수사항) 및 Methods(작업 방법)가 정의된 파일 저장 및 실행
- Sunny가 직접 진행한 SSAL Works(예시) 프로젝트의 모든 문서 및 소스코드 파일을 복사해서 저장해놓고 참조
- P0~P3 및 S0~S5의 10단계로 구분된 진행 프로세스에 의한 프로젝트 진도 관리
- 각 단계별 업무별로 제시되어 있는 안내문과 Order Sheet 템플릿을 활용하여 실제의 Order Sheet를 작성해서 Claude Code에 전달하고 작업 결과를 Reports에서 불러오기
- 개발작업 용 Project SAL Grid 생성(작업지시서 및 검증지시서 포함)하여 22개 속성 관리
- 빌더 계정 사용 매뉴얼(PDF) 다운로드
- AI Tutor를 활용하여 SSAL Works에 구비된 지식에 대해 질문해서 답변받기
- AI(ChatGPT, Gemini, Perplexity)에게 질문해서 답변받기

## SSAL Works 해설

**Claude Code**는 Anthropic이 개발한 AI 도구입니다. 터미널에서 실행되며, 사용자의 지시를 받아 코드를 작성하고, 파일을 만들고, 프로젝트를 관리합니다. SSAL Works는 이 Claude Code를 핵심 도구로 사용합니다.

**3차원 SAL Grid**는 Stage(단계) × Area(영역) × Level(순서)의 3차원 좌표계입니다. 풀스택 웹사이트 개발에 필요한 모든 작업(Task)을 이 좌표계 위에 배치하고, 각 Task를 22개 속성으로 관리합니다. AI에게 작업을 지시하고, 실행 결과를 검증하고, 전체 프로젝트를 통제하는 핵심 도구입니다.

**풀스택 웹사이트**란 프론트엔드(사용자가 보는 화면)와 백엔드(서버, 데이터베이스, API)가 모두 갖춰진 완전한 웹사이트를 말합니다. 단순한 랜딩 페이지나 홍보용 웹사이트가 아니라, 회원가입, 로그인, 결제, 데이터 저장, 관리자 기능 등 실제 비즈니스를 운영할 수 있는 완전한 웹사이트입니다.

## SSAL이라는 명칭의 의미

SSAL이라는 명칭은 두 가지 의미가 결합되어 있습니다.

첫째, **S + SAL**입니다. S는 개발자 Sunny의 성씨 첫 글자이고, SAL은 Stage(단계), Area(영역), Level(레벨)의 약자로서 **3차원 좌표계**를 표현합니다.

둘째, **쌀**입니다. SSAL의 한글 발음은 "쌀"입니다. 쌀은 한국인에게 핵심 먹을거리입니다.

SSAL Works는 마치 **황금쌀 방앗간**처럼, 창의적인 아이디어를 가져와서 돈을 버는 풀스택 웹사이트를 만드는 곳입니다. 빌더가 만드는 웹사이트는 사용자에게 돈을 벌어다주는 핵심 먹을거리가 됩니다.

## SSAL Works는 "바이브 코딩" 도구가 아닙니다

바이브 코딩이란 체계 없이 AI에게 "이거 해줘"라고만 시키는 방식입니다. 이렇게 하면 파일과 폴더가 여기저기 난립하고, 코드가 뒤엉키고, 나중에 수정이 불가능해집니다. 토큰 비용만 낭비되고 엉터리 결과물이 나옵니다.

SSAL Works는 정반대입니다. P0부터 S5까지 10단계 진행 프로세스로 프로젝트 전체를 체계적으로 관리합니다. SAL Grid로 모든 작업을 3차원 좌표계 위에서 관리하고, Order Sheet로 AI에게 작업을 체계적으로 지시합니다. 각 Task는 22개 속성으로 추적되며, 작업자와 검증자가 분리된 검증 시스템을 갖추고 있습니다.

여기에 더해 AI가 지켜야 할 체계를 세 가지로 정리해놓았습니다. Rules(7대 작업 규칙)는 파일명, 저장 위치, Area/Stage 매핑, Grid 작성법, 실행 프로세스, 검증 기준, Task 관리 방법을 정의합니다. Compliance(AI 12대 준수사항)는 AI가 반드시 지켜야 할 행동 원칙을 명시합니다. Methods(작업 방법)는 Supabase 같은 외부 서비스 연동 시 구체적인 실행 방법을 제공합니다.

AI가 아무리 뛰어나도 관리 시스템 없이는 제대로 일할 수 없습니다. SSAL Works는 P0~S5 10단계 진행 프로세스, 3차원 좌표계 SAL Grid, 작업 지시서 Order Sheet, 22개 속성으로 관리되는 Task, 작업자와 검증자가 분리된 검증 시스템, 그리고 7대 Rules, 12대 Compliance, Methods까지 모두 갖춘 체계적인 개발 방법론 플랫폼입니다.

## SSAL Works에서의 작업 방식

SSAL Works에서는 사용자와 AI가 역할을 분담합니다.

**AI(Claude Code)가 담당하는 것:**
- 코딩, 문법, 도구 사용, 반복 작업, 기술적 구현

**인간(사용자)이 담당하는 것:**
- 무엇을 만들 것인지 결정, 방향 결정, 비즈니스 모델 설계, 최종 승인

쉽게 말해서, **"무엇을 만들 것인가"는 인간이 결정**하고, **"어떻게 만들 것인가"는 AI가 담당**합니다.

## SSAL Works는 누구를 위한 플랫폼인가?

SSAL Works는 다음과 같은 분들을 위한 플랫폼입니다.

- **스타트업**: 아이디어는 있지만 코딩을 할 줄 모르는 분
- **직장인 부업**: 퇴근 후와 주말을 활용해서 웹서비스를 만들고 싶은 분
- **은퇴 후 시니어**: 새로운 일거리를 찾고, 경험과 노하우를 살리고 싶은 분
- **기존 사업자**: 기존 사업에 맞춤형 웹사이트를 도입하고 싶은 분

## 빌더란 무엇인가?

SSAL Works에서는 사용자를 **빌더(Builder)**라고 부릅니다.

빌더는 단순히 웹사이트만을 만드는 사람이 아니라, 웹사이트를 통해 비즈니스를 실현하는 사람입니다. 빌더는 기획하고, 의사결정하고, 방향을 정합니다. AI는 빌더의 지시에 따라 코딩을 수행합니다.

## SSAL Works에서 일반(무료) 회원으로 이용 가능한 기능

**SSAL Works의 무료 일반회원 가입만으로** 다음 콘텐츠와 기능을 이용할 수 있습니다.

### 콘텐츠 열람 (무제한)

- **Books 80편**: 1권 Claude/Claude Code 사용법 (34편), 2권 풀스택 웹사이트 개발 (34편), 3권 프로젝트 관리 방법 (12편)
- **실전 Tips 65개**: 18개 카테고리별 실무 팁
- **외부 연동 가이드 5가지**: 데이터베이스 설정, 회원인증 설정, 이메일 시스템 설정, 배포/도메인 설정, 결제 시스템 설정

### 주요 기능

- **공지사항**: 플랫폼 공지사항 열람
- **My Page**: 프로필, 계정 정보 관리
- **인앱 알림**: 시스템 알림 수신
- **SAL Grid 예시 열람**: SSAL Works 프로젝트의 SAL Grid 구조 확인 (웹)
- **Order Sheet 템플릿 보기**: AI에게 작업 지시하는 32개 표준 양식 열람
- **Stage별 안내문 열람**: 각 개발 단계의 안내문 확인

→ **무료로 충분히 둘러본 후, 유용하다고 판단되면 빌더 계정을 개설하시면 됩니다.**

## SSAL Works에서 빌더 계정 개설자가 추가로 이용 가능한 기능

SSAL Works에 빌더 계정을 개설하면 일반 회원 기능에 **추가로** 다음 기능을 이용할 수 있습니다.

### 프로젝트 관리

- **새로운 프로젝트 등록**: 본인의 웹사이트 프로젝트 생성
- **진행 프로세스 관리**: P0~S5 단계별 진행 상황 추적
- **Project SAL Grid 생성**: 본인 프로젝트용 SAL Grid 생성 및 관리

### 개발 도구

- **Order Sheet 전달하기**: 작성한 Order Sheet를 로컬에 저장하여 Claude Code에 전달
- **Reports 불러오기**: Claude Code 작업 결과 리포트 열람
- **Dev Package 다운로드**: AI 협업 개발 패키지 전체 다운로드
- **매뉴얼 다운로드**: PDF 파일로 다운로드 받아서 활용
- **예시 프로젝트 소스코드 및 문서**: SSAL Works 전체 소스코드 및 문서를 Google Drive를 통해 열람/다운로드

### AI Q&A 서비스

- **ChatGPT**: 코드 작성, 문서 생성, 일반 개발 질문
- **Gemini**: 코드 리뷰, 설계 관련 질문
- **Perplexity**: 검색 기반 정보, 최신 기술 동향

### 코칭 서비스

- **Sunny에게 질문하기**: 개발/코칭/자문 1:1 실시간 질의응답
- **3개월 1:1 맞춤형 코칭**: Sunny가 직접 코칭 (개발 + 창업 + 경영 자문)

## 3개월 1:1 맞춤형 코칭 프로그램

SSAL Works에 빌더 계정을 개설하면, 처음 3개월 동안 Sunny가 직접 1:1로 맞춤형 코칭을 제공합니다.

### Sunny는 누구인가?

현직 공인회계사이자 스타트업 액셀러레이터입니다. 2025년 5월부터 7개월간 매일 평균 12시간 이상, 누적 2,500시간 이상을 AI와 함께 작업했습니다. 그 중 웹사이트 개발은 10월부터 시작해서, 3개월도 안 되는 기간에 풀스택 웹사이트 3개를 혼자서 완성했습니다.

### 코칭에서 다루는 내용

개발 코칭, 창업 코칭, 경영 자문

### 코칭의 가치

혼자 했으면 수개월 걸릴 일을 코칭을 통해 단축할 수 있습니다. 검색해도 안 나오는 실전 노하우, 삽질을 줄이는 방법, 올바른 방향 설정까지. 3개월 집중 코칭으로 빌더는 AI와 협업하는 개발 역량을 갖추게 됩니다.

## SSAL Works 빌더 계정 개설비

현재 개설비는 **300만원 (얼리버드, 부가세 포함)**입니다. 향후 **3,000만원까지** 단계적으로 인상될 예정입니다.

### 50% 환불 인센티브

얼리버드 300만원의 경우, 3개월 내에 웹사이트를 완성하고 서비스를 시작하여 고객 30명을 확보하면 개설비의 **50% (150만원)**를 환불해드립니다.

빌더의 성공이 곧 SSAL Works의 성공입니다. 열심히 하시는 분께 인센티브로 보답합니다.

## SSAL Works 플랫폼 이용료

처음 3개월간 이용료는 **면제**됩니다.

4개월차부터 **월 5만원 (부가세 포함)**의 이용료가 발생합니다.

## 지금 시작하세요

지금이 가장 유리한 시점입니다. 첫째, 개설비가 가장 저렴합니다. 현재 얼리버드 300만원이지만, 플랫폼이 성장하면서 3,000만원까지 단계적으로 인상됩니다. 둘째, 예시 프로젝트가 계속 확대됩니다. 현재 SSAL Works 1개의 예시 프로젝트가 곧 50개, 100개로 늘어납니다. 나중에 시작하면 더 풍부한 예시를 참고할 수 있지만, 그때는 개설비도 올라가 있습니다. 셋째, 빌더 계정은 양도가 가능합니다. 본인이 웹사이트를 완성한 후, 계정을 다른 사람에게 양도할 수 있습니다. 지금 저렴하게 개설한 계정의 가치는 시간이 갈수록 높아집니다.
