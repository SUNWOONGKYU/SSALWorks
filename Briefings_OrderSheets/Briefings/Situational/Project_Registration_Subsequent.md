# 새 프로젝트 폴더 준비 안내

> **두 번째 이후 프로젝트용 안내입니다.**

---

## 프로젝트가 등록되었습니다!

개발을 시작하려면 **로컬 PC에 새 프로젝트 폴더**가 필요합니다.

개발 도구(Git, Node.js, Claude Code)는 이미 설치되어 있으므로 폴더만 준비하면 됩니다.

---

## 새 프로젝트 폴더 준비

### Dev Package 새로 다운로드

**1단계:** My Page → 자료 다운로드에서 Dev Package 다운로드

**2단계:** ZIP 파일 압축 해제

**3단계:** 폴더명을 새 프로젝트명으로 변경

**4단계:** 원하는 위치에 폴더 이동

**예시:**
- 다운로드한 파일: `SSAL_Works_Dev_Package.zip`
- 압축 해제 후 폴더명 변경: `MyNewProject`
- 최종 위치: `C:\Projects\MyNewProject`

---

## 다음 단계

**1.** 위 방법으로 폴더 준비

**2.** 폴더에서 터미널 열기

**3.** `claude` 명령어로 Claude Code 실행

**4.** "개발 환경 확인해줘"라고 말하기 → Claude Code가 설정을 도와줍니다

**5.** 개발 시작!

> **📌 .env와 .ssal-project.json**: Dev Package 다운로드 시 자동 생성됩니다. 별도 설정이 필요 없습니다.
