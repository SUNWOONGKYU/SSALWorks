# 새 프로젝트 폴더 준비 안내

> **두 번째 이후 프로젝트용 안내입니다.**

---

## 프로젝트가 등록되었습니다!

개발을 시작하려면 **로컬 PC에 새 프로젝트 폴더**가 필요합니다.

개발 도구(Git, Node.js, Claude Code)는 이미 설치되어 있으므로 폴더만 준비하면 됩니다.

---

## 새 프로젝트 폴더 준비

### Dev Package 새로 다운로드

**순서:**

| 단계 | 할 일 |
|:----:|------|
| 1 | **My Page > 자료 다운로드**에서 Dev Package 다운로드 |
| 2 | ZIP 파일 압축 해제 |
| 3 | 폴더명을 새 프로젝트명으로 변경 |
| 4 | 원하는 위치에 폴더 이동 |

**예시:**
- 다운로드: `SSAL_Works_Dev_Package.zip`
- 압축 해제 후 폴더명 변경: `MyNewProject`
- 이동: `C:\Projects\MyNewProject`
