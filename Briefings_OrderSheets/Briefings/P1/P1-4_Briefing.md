# Patent

## 단계 개요

프로젝트의 **핵심 기술에 대한 특허 출원**을 준비합니다.

이 프로젝트에서는 **SAL 3D Grid 기반 작업 오케스트레이션 시스템**이라는 혁신적인 기술을 특허로 보호합니다.

## 발명의 명칭

**SAL 3D Grid 기반 식별자 인코딩·해석 및 블록체인 스타일 ID 체인을 이용한 작업 오케스트레이션 시스템, 방법, 및 저장매체**

## 핵심 기술

### SAL 3D Grid
- **Stage(단계)**: 프로젝트 진행 단계 (S1~S5)
- **Area(영역)**: 작업 분야 (F, BA, D, S 등 11개)
- **Level(계층)**: 작업 깊이 (L1~L3)

### 주요 혁신
- **SAL ID**: 간결한 식별자로 좌표·의존성·병렬성 인코딩
- **DAG 자동 생성**: ID 파싱만으로 의존관계 그래프 자동 구축
- **블록체인 스타일 ID 체인**: 작업 이동/변경 이력을 불변하게 보존
- **3D 시각화**: Stage×Area×Level 공간에서 작업 배치 시각화

## 종래 기술 대비 차별점

| 종래 기술 | 본 발명 |
|----------|--------|
| DAG를 수동 정의 | SAL ID만으로 DAG 자동 생성 |
| 이력 단절 문제 | 블록체인 스타일로 이력 완전 보존 |
| 2D 시각화 한계 | 3D Grid 기반 직관적 시각화 |
| 도메인별 비일관성 | 통합 식별체계로 일관성 확보 |
