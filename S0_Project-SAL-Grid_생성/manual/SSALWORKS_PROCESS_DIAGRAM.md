```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                         진행률 계산 방식 비교                                    │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  ╔═══════════════════════════════════════════════════════════════════════════╗ │
│  ║                    P0 ~ S0: 폴더/파일 기반 계산                            ║ │
│  ╠═══════════════════════════════════════════════════════════════════════════╣ │
│  ║                                                                           ║ │
│  ║   데이터 소스: 로컬 폴더 구조                                              ║ │
│  ║                                                                           ║ │
│  ║   ┌─────────────────────────────────────────────────────────────────┐    ║ │
│  ║   │  P0_작업_디렉토리_구조_생성/                                     │    ║ │
│  ║   │  ├── Project_Directory_Structure.md  ← 파일 있음 = 1개 완료     │    ║ │
│  ║   │  └── Project_Status.md               ← 파일 있음 = 1개 완료     │    ║ │
│  ║   │                                                                 │    ║ │
│  ║   │  진행률 = 파일 있는 폴더 수 / 전체 하위 폴더 수 × 100%          │    ║ │
│  ║   │         = 2 / 2 = 100%                                          │    ║ │
│  ║   └─────────────────────────────────────────────────────────────────┘    ║ │
│  ║                                                                           ║ │
│  ║   계산 함수: calculatePhaseProgress() in build-progress.js               ║ │
│  ║                                                                           ║ │
│  ╚═══════════════════════════════════════════════════════════════════════════╝ │
│                                                                                 │
│  ╔═══════════════════════════════════════════════════════════════════════════╗ │
│  ║                    S1 ~ S5: SAL Grid JSON 기반 계산                       ║ │
│  ╠═══════════════════════════════════════════════════════════════════════════╣ │
│  ║                                                                           ║ │
│  ║   데이터 소스: S0_Project-SAL-Grid_생성/method/json/data/                 ║ │
│  ║                                                                           ║ │
│  ║   ┌─────────────────────────────────────────────────────────────────┐    ║ │
│  ║   │  index.json                                                     │    ║ │
│  ║   │  └── task_ids: ["S1M1", "S1D1", "S2F1", ...]                   │    ║ │
│  ║   │                                                                 │    ║ │
│  ║   │  grid_records/                                                  │    ║ │
│  ║   │  ├── S1M1.json  { "stage": 1, "task_status": "Completed" }     │    ║ │
│  ║   │  ├── S1D1.json  { "stage": 1, "task_status": "Completed" }     │    ║ │
│  ║   │  ├── S2F1.json  { "stage": 2, "task_status": "Completed" }     │    ║ │
│  ║   │  └── ...                                                        │    ║ │
│  ║   │                                                                 │    ║ │
│  ║   │  진행률 = Completed 상태 Task 수 / 해당 Stage 전체 Task 수 × 100% ║ │
│  ║   │  S1 = 9/9 = 100%, S2 = 17/17 = 100%, ...                       │    ║ │
│  ║   └─────────────────────────────────────────────────────────────────┘    ║ │
│  ║                                                                           ║ │
│  ║   계산 함수: calculateStageProgressFromJSON() in build-progress.js       ║ │
│  ║                                                                           ║ │
│  ╚═══════════════════════════════════════════════════════════════════════════╝ │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## 5. 웹에서 진행률 표시 (index.html)

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                    index.html에서 진행률 표시 흐름                               │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐   │
│  │  [STEP 1] 로그인 확인                                                    │   │
│  │  ─────────────────────────────────────────────────────────────────────  │   │
│  │                                                                         │   │
│  │  const { data: { session } } = await supabaseClient.auth.getSession();  │   │
│  │                                                                         │   │
│  │  로그인 안 됨 → resetAllProgressToZero() → 모든 진행률 0% 표시          │   │
│  │  로그인 됨 → STEP 2로                                                   │   │
│  │                                                                         │   │
│  └─────────────────────────────────────────────────────────────────────────┘   │
│                                      │                                          │
│                                      ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────────────┐   │
│  │  [STEP 2] DB에서 진행률 조회                                             │   │
│  │  ─────────────────────────────────────────────────────────────────────  │   │
│  │                                                                         │   │
│  │  const { data } = await supabaseClient                                  │   │
│  │    .from('project_phase_progress')                                      │   │
│  │    .select('*')                                                         │   │
│  │    .eq('project_id', projectId);                                        │   │
│  │                                                                         │   │
│  │  결과: [{ phase_code: 'P0', progress: 100 }, { phase_code: 'S1', ... }] │   │
│  │                                                                         │   │
│  └─────────────────────────────────────────────────────────────────────────┘   │
│                                      │                                          │
│                                      ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────────────┐   │
│  │  [STEP 3] 사이드바 진행률 업데이트                                       │   │
│  │  ─────────────────────────────────────────────────────────────────────  │   │
│  │                                                                         │   │
│  │  data.forEach(phase => {                                                │   │
│  │    if (phase.phase_code === 'P0' || phase.phase_code === 'S0') {        │   │
│  │      updateSpecialProgress(phase.phase_code, phase.progress);           │   │
│  │    } else if (phase.phase_code.startsWith('P')) {                       │   │
│  │      updatePrepProgressByCode(phase.phase_code, phase.progress);        │   │
│  │    } else if (phase.phase_code.startsWith('S')) {                       │   │
│  │      updateStageProgress(phase.phase_code, phase.progress);             │   │
│  │    }                                                                    │   │
│  │  });                                                                    │   │
│  │                                                                         │   │
│  │  → .process-progress-fill 너비 조정                                     │   │
│  │  → .process-percent 텍스트 업데이트                                     │   │
│  │  → 100%면 .completed 클래스 추가                                        │   │
│  │                                                                         │   │
│  └─────────────────────────────────────────────────────────────────────────┘   │
│                                      │                                          │
│                                      ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────────────┐   │
│  │  [결과] 사이드바 진행률 표시                                             │   │
│  │  ─────────────────────────────────────────────────────────────────────  │   │
│  │                                                                         │   │
│  │  ┌────────────────────────────────────┐                                 │   │
│  │  │  준비 과정                          │                                 │   │
│  │  │  ├── P0. 디렉토리 구조 ████████ 100%│                                 │   │
│  │  │  ├── P1. 사업계획    ████████ 100% │                                 │   │
│  │  │  ├── P2. 프로젝트 기획████████ 100%│                                 │   │
│  │  │  ├── P3. 프로토타입  ████████ 100% │                                 │   │

```
┌─────────────────────────────────────────────────────────────────────────────────┐
