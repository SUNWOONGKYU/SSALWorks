# 【서류명】 명세서

---

## 【발명의 명칭】

### 【국문명칭】
SAL 3D Grid 기반 식별자 인코딩해석 및 블록체인 연동 시스템

### 【영문명칭】
SAL 3D Grid-Based Identifier Encoding/Interpreting and Blockchain Integration System

---

## 【기술분야】

본 발명은 3차원 좌표 기반의 식별자 인코딩 및 해석 시스템에 관한 것으로, 더욱 상세하게는 Stage(단계), Area(영역), Level(수준)의 3차원 그리드 좌표를 활용하여 프로젝트 작업 항목에 대한 고유 식별자를 생성하고, 이를 블록체인 네트워크와 연동하여 작업 이력의 불변성 검증 및 추적성을 확보하는 시스템 및 방법에 관한 것이다.

---

## 【배경기술】

종래의 프로젝트 관리 시스템에서는 작업 항목을 식별하기 위해 단순 일련번호 또는 계층적 넘버링 체계를 사용하여 왔다. 그러나 이러한 방식은 다음과 같은 문제점들을 가지고 있다.

첫째, 기존의 식별자 체계는 작업의 진행 단계(Stage), 담당 영역(Area), 세부 수준(Level)을 동시에 표현하지 못하여 작업의 다차원적 위치를 직관적으로 파악하기 어렵다. 예를 들어, "TASK-001"이라는 식별자만으로는 해당 작업이 어느 단계에 있고, 어떤 팀이 담당하며, 얼마나 세부적인 작업인지를 즉시 알 수 없다.

둘째, 종래의 시스템은 작업 이력의 위변조 가능성에 취약하다. 중앙화된 데이터베이스에 저장된 작업 기록은 관리자에 의해 임의로 수정되거나 삭제될 수 있으며, 이로 인해 프로젝트 감사(Audit) 시 신뢰성 문제가 발생한다.

셋째, 서로 다른 프로젝트 관리 도구 간의 상호운용성이 부족하다. 각 시스템이 고유한 식별자 체계를 사용하므로, 외부 시스템과의 연동 시 식별자 매핑 작업이 필요하며 이 과정에서 오류가 발생할 수 있다.

따라서 작업 항목의 다차원적 위치를 직관적으로 표현하면서도, 이력의 불변성을 보장하고, 시스템 간 상호운용성을 확보할 수 있는 새로운 식별자 체계 및 시스템이 요구된다.

## 【발명의 내용】

### 【해결하려는 과제】

본 발명이 해결하고자 하는 첫 번째 과제는 프로젝트 작업 항목의 다차원적 위치(단계, 영역, 수준)를 단일 식별자로 직관적으로 표현할 수 있는 식별자 인코딩 체계를 제공하는 것이다.

본 발명이 해결하고자 하는 두 번째 과제는 블록체인 기술을 활용하여 작업 이력의 불변성을 보장하고, 위변조 시도를 검출할 수 있는 시스템을 제공하는 것이다.

본 발명이 해결하고자 하는 세 번째 과제는 표준화된 문법 규칙에 기반한 식별자 해석기를 제공하여, 이기종 시스템 간의 상호운용성을 확보하는 것이다.

### 【과제의 해결 수단】

상기 과제를 해결하기 위해 본 발명은 SAL 3D Grid 기반 식별자 인코딩해석 및 블록체인 연동 시스템을 제공한다.

본 발명에 따른 시스템은 식별자 생성부(100), 식별자 해석부(200), 블록체인 연동부(300), 저장부(400), 및 시각화부(500)를 포함한다.

상기 식별자 생성부(100)는 사용자로부터 입력받은 작업 항목 정보를 기반으로 SAL 3D Grid 좌표를 산출하고, 해당 좌표를 인코딩하여 고유 식별자를 생성한다. 상기 SAL 3D Grid 좌표는 Stage 값(1~99의 정수), Area 코드(2자리 대문자 알파벳), Level 값(1~99의 정수)으로 구성되며, 선택적으로 Variant 코드(소문자 알파벳)를 포함할 수 있다.

상기 식별자 해석부(200)는 BNF(Backus-Naur Form) 문법 규칙에 기반한 파서를 포함하며, 입력된 SAL 식별자 문자열을 파싱하여 Stage, Area, Level, Variant 각 구성요소를 추출한다.

상기 블록체인 연동부(300)는 생성된 SAL 식별자와 해당 작업 항목의 메타데이터를 해시 함수로 처리하여 블록체인 네트워크에 기록한다. 이를 통해 작업 이력의 불변성을 보장하고, 추후 검증 요청 시 블록체인에 기록된 해시값과 현재 데이터의 해시값을 비교하여 위변조 여부를 판별한다.

상기 저장부(400)는 SAL 식별자, 작업 항목 정보, 블록체인 트랜잭션 ID, 해시값 등을 매핑하여 저장하며, 식별자 기반 검색 및 조회 기능을 제공한다.

상기 시각화부(500)는 SAL 3D Grid 좌표를 기반으로 프로젝트 전체 작업 항목들을 3차원 공간상에 시각적으로 표현하여, 사용자가 프로젝트 진행 현황을 직관적으로 파악할 수 있도록 한다.

### 【발명의 효과】

본 발명에 따르면 다음과 같은 효과가 있다.

첫째, SAL 3D Grid 좌표 체계를 통해 작업 항목의 단계(Stage), 영역(Area), 수준(Level)을 단일 식별자로 표현할 수 있어, 식별자만 보고도 해당 작업의 프로젝트 내 위치를 즉시 파악할 수 있다.

둘째, 블록체인 연동을 통해 모든 작업 이력이 불변적으로 기록되므로, 프로젝트 감사 시 신뢰성 있는 증적 자료를 제공할 수 있다.

셋째, BNF 문법 기반의 표준화된 식별자 해석기를 제공함으로써, 다양한 프로젝트 관리 도구들이 SAL 식별자를 해석하고 활용할 수 있어 시스템 간 상호운용성이 향상된다.

넷째, 3차원 시각화를 통해 대규모 프로젝트에서도 전체 작업 현황을 한눈에 파악할 수 있어, 프로젝트 관리 효율성이 크게 향상된다.

## 【발명을 실시하기 위한 구체적인 내용】

이하, 첨부된 도면을 참조하여 본 발명의 바람직한 실시예를 상세히 설명한다.

### 1. 시스템 전체 구성

도 1을 참조하면, 본 발명의 일 실시예에 따른 SAL 3D Grid 기반 식별자 인코딩해석 및 블록체인 연동 시스템(10)은 식별자 생성부(100), 식별자 해석부(200), 블록체인 연동부(300), 저장부(400), 시각화부(500), 및 통신부(600)를 포함한다.

상기 시스템(10)은 사용자 단말기(20)와 네트워크(30)를 통해 연결되며, 블록체인 네트워크(40)와 연동된다.

### 2. SAL 3D Grid 좌표 체계

도 2를 참조하면, SAL 3D Grid 좌표 체계는 3차원 공간상에 프로젝트 작업 항목들을 배치하기 위한 좌표계이다. X축은 Stage(단계)를 나타내며 1부터 99까지의 정수 값을 가진다. Y축은 Area(영역)를 나타내며 2자리 대문자 알파벳(AA~ZZ)으로 표현된다. Z축은 Level(수준)을 나타내며 1부터 99까지의 정수 값을 가진다.

예를 들어, "S3FE5"라는 SAL 식별자는 Stage=3, Area=FE, Level=5인 좌표를 나타낸다.

### 3. SAL 식별자 구조

도 3을 참조하면, SAL 식별자는 다음과 같은 구조를 가진다:

- 접두어: "S" (SAL을 나타내는 고정 문자)
- Stage 값: 1~2자리 숫자 (1~99)
- Area 코드: 2자리 대문자 알파벳 (AA~ZZ)
- Level 값: 1~2자리 숫자 (1~99)
- Variant 코드: 선택적, 1자리 소문자 알파벳 (a~z)

유효한 SAL 식별자의 예시:
- "S1AA1" : Stage 1, Area AA, Level 1
- "S10FE5" : Stage 10, Area FE, Level 5
- "S3BE7a" : Stage 3, Area BE, Level 7, Variant a

### 4. 식별자 생성부(100)의 구성 및 동작

도 4를 참조하면, 식별자 생성부(100)는 입력 처리 모듈(110), 좌표 산출 모듈(120), 인코딩 모듈(130), 및 유효성 검증 모듈(140)을 포함한다.

입력 처리 모듈(110)은 사용자로부터 작업 항목 정보를 입력받는다.

좌표 산출 모듈(120)은 입력된 정보를 기반으로 SAL 3D Grid 좌표를 산출한다.

인코딩 모듈(130)은 산출된 좌표를 SAL 식별자 문자열로 인코딩한다.

유효성 검증 모듈(140)은 생성된 식별자가 BNF 문법 규칙을 준수하는지 검증한다.

### 5. 식별자 해석부(200)의 구성 및 동작

도 5를 참조하면, 식별자 해석부(200)는 렉서 모듈(210), 파서 모듈(220), 및 결과 출력 모듈(230)을 포함한다.

렉서 모듈(210)은 입력된 SAL 식별자 문자열을 토큰 단위로 분리한다.

파서 모듈(220)은 BNF 문법 규칙에 따라 토큰들을 파싱하여 구문 트리를 생성한다.

결과 출력 모듈(230)은 파싱 결과를 JSON, XML 등 다양한 포맷으로 출력한다.

### 6. 블록체인 연동부(300)의 구성 및 동작

도 6을 참조하면, 블록체인 연동부(300)는 해시 생성 모듈(310), 트랜잭션 생성 모듈(320), 블록체인 통신 모듈(330), 및 검증 모듈(340)을 포함한다.

해시 생성 모듈(310)은 SAL 식별자와 작업 항목 메타데이터를 입력으로 받아 SHA-256 해시값을 생성한다.

트랜잭션 생성 모듈(320)은 생성된 해시값을 블록체인에 기록하기 위한 트랜잭션을 생성한다.

블록체인 통신 모듈(330)은 트랜잭션을 블록체인 네트워크(40)에 전송하고 트랜잭션 ID를 수신한다.

검증 모듈(340)은 검증 요청 시 해시값을 재계산하여 블록체인에 기록된 해시값과 비교한다.

### 7. 저장부(400)의 구성

저장부(400)는 SAL 식별자 테이블(410), 작업 항목 테이블(420), 블록체인 매핑 테이블(430), 및 이력 테이블(440)을 포함한다.

SAL 식별자 테이블(410)은 생성된 모든 SAL 식별자와 생성 시간, 생성자 정보를 저장한다.

작업 항목 테이블(420)은 각 SAL 식별자에 대응하는 작업 항목의 상세 정보를 저장한다.

블록체인 매핑 테이블(430)은 SAL 식별자와 블록체인 트랜잭션 ID, 해시값의 매핑 정보를 저장한다.

이력 테이블(440)은 작업 항목의 상태 변경 이력을 저장한다.

### 8. 시각화부(500)의 구성 및 동작

시각화부(500)는 좌표 변환 모듈(510), 렌더링 모듈(520), 및 상호작용 모듈(530)을 포함한다.

좌표 변환 모듈(510)은 SAL 식별자의 Stage, Area, Level 값을 3차원 공간의 X, Y, Z 좌표로 변환한다.

렌더링 모듈(520)은 작업 상태에 따라 구분된 색상으로 작업 항목을 3차원 객체로 렌더링한다.

상호작용 모듈(530)은 사용자가 3차원 공간을 회전, 확대/축소, 이동할 수 있는 인터페이스를 제공한다.

### 9. SAL 식별자 생성 방법

도 7을 참조하면, 본 발명에 따른 SAL 식별자 생성 방법은 다음 단계들을 포함한다.

S710 단계에서, 식별자 생성부(100)는 사용자로부터 작업 항목 정보를 입력받는다.

S720 단계에서, 좌표 산출 모듈(120)은 입력된 정보를 기반으로 Stage, Area, Level 값을 산출한다.

S730 단계에서, 인코딩 모듈(130)은 산출된 값들을 SAL 식별자 문자열로 인코딩한다.

S740 단계에서, 유효성 검증 모듈(140)은 생성된 식별자의 문법 유효성과 중복 여부를 검증한다.

S750 단계에서, 해시 생성 모듈(310)이 식별자와 메타데이터의 해시값을 생성한다.

S760 단계에서, 트랜잭션 생성 모듈(320)이 블록체인 트랜잭션을 생성하고 전송한다.

S770 단계에서, 저장부(400)에 식별자, 작업 항목 정보, 트랜잭션 ID가 저장된다.

S780 단계에서, 생성된 SAL 식별자가 사용자에게 반환된다.

### 10. 블록체인 기반 이력 검증 방법

도 8을 참조하면, 본 발명에 따른 블록체인 기반 이력 검증 방법은 다음 단계들을 포함한다.

S810 단계에서, 검증 모듈(340)은 검증 대상 SAL 식별자를 입력받는다.

S820 단계에서, 저장부(400)에서 해당 식별자의 원본 데이터와 저장된 해시값을 조회한다.

S830 단계에서, 조회된 원본 데이터를 기반으로 해시값을 재계산한다.

S840 단계에서, 블록체인 매핑 테이블(430)에서 해당 식별자의 트랜잭션 ID를 조회한다.

S850 단계에서, 블록체인 네트워크(40)에서 해당 트랜잭션에 포함된 해시값을 조회한다.

S860 단계에서, 재계산된 해시값과 블록체인에서 조회된 해시값을 비교한다.

S870 단계에서, 두 해시값이 일치하면 "무결성 유지"를 반환하고, 불일치하면 "위변조 감지"를 반환한다.
