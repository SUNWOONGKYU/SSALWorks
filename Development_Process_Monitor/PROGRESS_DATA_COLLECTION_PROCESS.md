# SSAL Works 진행률 데이터 수집 프로세스

> **이 문서의 목적:** SSAL Works 프로젝트의 진행률이 어떻게 수집되고, 어디에 저장되고, 어떻게 표시되는지 상세히 설명
>
> **적용 대상:** SSAL Works 내부 프로젝트

---

# Part 1: 개요

## 1.1 한 줄 요약

```
git commit → pre-commit hook → 진행률 계산 → JSON 저장 → DB 업로드 → 웹 표시
```

## 1.2 핵심 질문과 답변

| 질문 | 답변 |
|------|------|
| **언제** 진행률이 수집되나요? | `git commit` 할 때마다 자동으로 |
| **무엇을** 수집하나요? | P0~S5 각 단계의 완료 항목 수와 진행률(%) |
| **어디서** 데이터를 가져오나요? | P0~S0: 폴더 구조, S1~S5: SAL Grid JSON 파일 |
| **어디에** 저장하나요? | 로컬 JSON 파일 + Supabase DB |
| **어떻게** 표시하나요? | index.html 사이드바에 진행률 바 표시 |

## 1.3 관련 파일 목록 (한눈에 보기)

```
프로젝트 루트/
│
├── .git/hooks/
│   └── pre-commit                    ← [1] 트리거: git commit 시 자동 실행
│
├── Development_Process_Monitor/
│   ├── build-progress.js             ← [2] 진행률 계산 스크립트
│   └── data/
│       └── phase_progress.json       ← [3] 계산 결과 저장 (중간 산출물)
│
├── scripts/
│   └── upload-progress.js            ← [4] DB 업로드 스크립트
│
├── P3_프로토타입_제작/Database/
│   └── .env                          ← [5] Supabase 인증 정보
│
├── .ssal-project.json                ← [6] 프로젝트 ID 설정
│
├── S0_Project-SAL-Grid_생성/method/json/data/
│   ├── index.json                    ← [7] Task ID 목록
│   └── grid_records/
│       ├── S1M1.json                 ← [8] 개별 Task 상태 (S1~S5 진행률 소스)
│       ├── S1D1.json
│       └── ...
│
└── index.html                        ← [9] 웹 표시 (사이드바 진행률)
```

```

## 4.2 스크립트의 역할

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│   build-progress.js가 하는 일:                                                  │
│                                                                                 │
│   1. P0~S0 폴더를 스캔해서 진행률 계산 (폴더/파일 기반)                         │

# Part 8: 수동 실행 및 트러블슈팅

## 8.1 수동 실행 방법

```bash
# 1. 진행률 계산만 (JSON 생성)
$ node Development_Process_Monitor/build-progress.js

# 2. DB 업로드만 (JSON → DB)
$ node scripts/upload-progress.js

# 3. 둘 다 (자동 - git commit 시)
$ git commit -m "작업 내용"
```

## 8.2 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| 진행률이 0%로 표시됨 | 로그인 안 됨 | 로그인 후 새로고침 |
| DB 업로드 실패 | .env 파일 없음/잘못됨 | .env 파일 확인 |
| S1~S5 진행률이 0% | JSON 파일 없음 | SAL Grid JSON 파일 생성 |
| 커밋 시 스크립트 에러 | Node.js 미설치 | Node.js 설치 |
