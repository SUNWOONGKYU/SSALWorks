## 왜 자동 주입이 필요한가?

| 방식 | 문제점 | 결과 |
|------|--------|------|
| **수동 설정** | 사용자가 직접 .ssal-project.json 수정 | 형식 오류 가능, 귀찮음, 설정 안 함 |
| **자동 주입** | 다운로드만 하면 끝 | project_id 정확히 일치, 바로 사용 가능 |

## 관련 파일

| 파일 | 위치 | 역할 |
|------|------|------|
| `.ssal-project.json` | 프로젝트 루트 | project_id 저장 (다운로드 시 자동 생성) |
| `build-progress.js` | Development_Process_Monitor/ | 진행률 계산, project_id 포함 |
| `upload-progress.js` | Development_Process_Monitor/DB_Method/ | phase_progress.json에서 project_id 읽어 DB 업로드 |
| `phase_progress.json` | Development_Process_Monitor/data/ | 계산된 진행률 저장 |

## getProjectId() 함수

`build-progress.js`에서 project_id를 읽는 함수:

```javascript
function getProjectId() {
    const projectConfigPath = path.join(PROJECT_ROOT, '.ssal-project.json');
    try {
        if (fs.existsSync(projectConfigPath)) {
            const config = JSON.parse(fs.readFileSync(projectConfigPath, 'utf-8'));
            return config.project_id || 'UNKNOWN_PROJECT';
        }
    } catch (e) {
        console.warn('.ssal-project.json 읽기 실패:', e.message);
    }
    return 'UNKNOWN_PROJECT';
}
```

## Pre-commit Hook 설정

`.git/hooks/pre-commit`:

```bash
#!/bin/sh
echo "Progress 데이터 수집 중..."

# 진행률 계산
node Development_Process_Monitor/build-progress.js

# DB 업로드 (SSAL Works 플랫폼 연동 시)
if [ -f "Development_Process_Monitor/DB_Method/upload-progress.js" ]; then
    node Development_Process_Monitor/DB_Method/upload-progress.js
fi

echo "Progress 업데이트 완료!"
```
